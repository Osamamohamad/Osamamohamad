## 🚀 Flagship Project

### ⚡ RoboApex — *EcoMind AI*
**Autonomous Smart Microgrid Gateway & Edge AI Energy Manager**

[![Demonstration Video](https://img.shields.io/badge/▶_Demonstration_Video-View_on_Google_Drive-DC2626?style=for-the-badge&logo=googledrive&logoColor=white)](https://drive.google.com/drive/folders/1AUyehbLXpmj71KQhAxq-5_csDmrZh76C)
![Top 6 Finalist](https://img.shields.io/badge/RoboDam_2026-Top_6_Finalist-F59E0B?style=for-the-badge)

</div>

**RoboApex** is a decentralized Home Energy Management System running across distributed ESP32 nodes that communicate through an **ESP-NOW mesh**. The system is designed for local coordination, with reported communication latency below 3 ms and no cloud reliance for node-to-node operation.

| | Feature | What it does |
|:--:|:--|:--|
| 🧠 | **Edge Neural Cortex** | Uses on-chip predictive thermal modeling to forecast room-temperature trends up to 30 minutes ahead |
| ⚡ | **Dynamic Peak Shaving** | Balances loads in real time to help protect solar inverters from high-demand devices such as EV chargers |
| 🗣️ | **Conversational SCADA** | Provides a web-based SCADA interface powered by **Groq LLaMA 3.3 70B** |
| 🔋 | **Solar ATS** | Automatically transfers between grid and solar power sources |
| 🚗 | **Smart EV Charging** | Manages EV charging alongside household energy use |
| 🛡️ | **Safety & Monitoring** | Supports safer, more informed energy management |

**Technology:** ESP32 · C++ · ESP-NOW · Edge AI · Groq · SCADA
