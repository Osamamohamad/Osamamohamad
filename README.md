## 🚀 Featured Project

<div align="center">

### ⚡ RoboApex — *EcoMind AI*
**Autonomous Smart Microgrid Gateway & Edge AI Energy Manager**

<a href="https://drive.google.com/drive/folders/1AUyehbLXpmj71KQhAxq-5_csDmrZh76C">
  <img src="https://img.shields.io/badge/Watch-Demonstration%20Video-FF0000?style=for-the-badge&logo=youtube&logoColor=white" alt="Watch demonstration video"/>
</a>
<img src="https://img.shields.io/badge/RoboDam-Top%206%20Finalist-F59E0B?style=for-the-badge" alt="RoboDam Top 6 finalist"/>

</div>

RoboApex is a **decentralized home energy management system** built around distributed ESP32 nodes communicating over an **ESP-NOW mesh**. It is designed to coordinate energy use locally, with reported communication latency below 3 ms and no cloud dependency for node-to-node communication.

| Capability | What it does |
|:--|:--|
| 🧠 **Edge Neural Cortex** | Forecasts room temperature trends up to 30 minutes ahead |
| ⚡ **Dynamic Peak Shaving** | Balances loads in real time to help protect solar inverters |
| 🗣️ **Conversational SCADA** | Provides a web-based SCADA interface powered by Groq LLaMA 3.3 70B |
| 🔋 **Solar ATS** | Automatically switches between grid and solar sources |
| 🚗 **Smart EV Charging** | Coordinates EV charging with household energy use |
| 🛡️ **Safety & Monitoring** | Supports safer, more informed energy management |

**Built with:** ESP32 · C++ · ESP-NOW · Edge AI · Groq · SCADA
