## 🚀 Flagship Project

<div align="center">

### ⚡ RoboApex — *EcoMind AI*
**Autonomous Smart Microgrid Gateway & Edge AI Energy Manager**

[![Repository](https://img.shields.io/badge/Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/YusufAbozeid/RobApex)
[![Demo Video](https://img.shields.io/badge/Demonstration_Video-FF0000?style=for-the-badge&logo=youtube&logoColor=white)](https://drive.google.com/drive/folders/1AUyehbLXpmj71KQhAxq-5_csDmrZh76C)
![Finalist](https://img.shields.io/badge/Top_6_Finalist-F59E0B?style=for-the-badge)

</div>

A **decentralized Home Energy Management System** running across distributed ESP32 nodes via **ESP-NOW mesh** (<3ms latency, zero cloud reliance).

| | Feature | What it does |
|:-:|---------|--------------|
| 🧠 | **Edge Neural Cortex** | On-chip predictive thermal modeling (dT/dt forecasting room temperature 30 min ahead) |
| ⚡ | **Dynamic Peak Shaving** | Protects solar inverters from EV chargers by balancing loads in real time |
| 🗣️ | **Conversational SCADA** | A web SCADA interface powered by **Groq LLaMA 3.3 70B** |
| 🔋 | **Solar ATS** | Automatic transfer between grid and solar sources |
| 🚗 | **Smart EV Charging** | Intelligent management of EV charging and energy usage |
| 🛡️ | **Safety & Monitoring** | Smarter energy usage while keeping safety first |
